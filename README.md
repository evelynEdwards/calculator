# Calculator lab project
## How to run calculator
Prerequisite: Python 3
Run: ./run.sh
Sample test: Enter 6,*,7; expect Result: 42.0
Stop: Ctrl+C
## How to test calculator
Prerequisites: Python 3, virtual environment
Activate SCCM4910 environment: source /opt/python-venv/sccm-4910/bin/activate
Run: ./check.sh
Expected result: 5 checks passed, QUALITY GATE PASSED
Exit status: 0 = passed, 1 = check(s) failed, 5 = checks not run
